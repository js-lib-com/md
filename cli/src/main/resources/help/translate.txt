Usage: mdt translate [options] [document-dir]

Translate document.md, revisions.md and document.properties from English to
Romanian using an OpenAI compatible chat completions API, by default the
local llama.cpp server, writing document_ro.md, revisions_ro.md and
document_ro.properties. A file is written only if fully translated.

Environment:
  OPENAI_BASE_URL  API base URL; default http://jarvis.local/v1
                   use https://api.openai.com/v1 for OpenAI
  OPENAI_API_KEY   API key; optional, required by OpenAI
  OPENAI_MODEL     model; default is the model loaded by server,
                   required by OpenAI, e.g. gpt-4o-mini
  TRANSLATE_PARALLEL
                   chunks translated concurrently; default 4

Options:
  -h, --help     Show this help
  -v, --verbose  Show debug messages and error stack traces
  -q, --quiet    Show errors only
